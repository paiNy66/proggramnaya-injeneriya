print(f"2. Разных людей: {dif}")

vis = {}
for code in ch:
    if code in vis:
        vis[code] += 1
    else:
        vis[code] = 1

most = max(vis, key=vis.get)
num = vis[most]

print(f"3. Работник {most} был чаще всех: {num} раз")

## Выводы

len(ch): Вычисляется общее количество выданных чеков. Функция len() подсчитывает все элементы в списке, включая повторяющиеся посещения.

set(ch): множество из списка чеков, что автоматически удаляет все дубликаты. Затем функция len() подсчитывает количество уникальных кодов работников.

vis: Создается словарь для подсчета частоты посещений каждого работника. С помощью цикла for перебираются все чеки и увеличивается счетчик для каждого кода.
